1 · Role / identity — “Agentūra” and “Pirkėjas” removed as top-level roles

beforeP0

The switcher rendered every held role verbatim — a legacy holder saw Pirkėjas and Agentūra as peer, switchable top-level spaces; customer was also offered under “Add role”.

after

The switcher renders base identities only: Asmens erdvė / Įmonės erdvė (+ admin badge for admins). Buy / sell / hire / agency are actions (cards under Įmonė). agency + customer fold into the company identity; both are availability:"hidden".

Files: lib/config/roles.ts (hide customer + baseIdentityForRole/BASE_IDENTITY_PRIMARY_ROLE), components/app/role-switcher.tsx (identity rendering), messages/{lt,en,ru}.json (auth.roleSwitcher.personSpace/companySpace). Guards: systemic-ux-sprint-v1, header-role-switcher-parity, role-no-silo-framing, company-role-simplicity.

3 · Skill evidence text — one deterministic status, no contradiction

beforeP0

“Paremta darbo įrašais: 6 iš 21” shown together with “Dar nėra darbo įrašų, kurie paremtų šiuos įgūdžius.”

after

One line from skillEvidenceStatus():

  • 0 / N → “Dar nėra darbo įrašų, kurie paremtų šiuos įgūdžius.”
  • 1…N-1 → “Kai kuriuos įgūdžius jau paremia darbo įrašai.”
  • N / N → “Visi šie įgūdžiai turi darbo įrašų pagrindimą.”

Files: lib/profile/skill-evidence.ts, components/app/profile-hub-overview.tsx, messages.*.profileHub.evidence.status_{none,some,all}. Guards: skill-evidence, profile-cv-evidence-hub.
