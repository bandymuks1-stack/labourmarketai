# Human imagery used by the design lab (Round 2)

Every file here was fetched from Wikimedia Commons and its licence was read
from the Commons API (`extmetadata.LicenseShortName`) at download time, not
assumed. Only PUBLIC DOMAIN and CC0 files were kept.

These are used ONLY inside `/{locale}/design/*` concept routes, as heavily
art-directed monochrome fragments — never as a hero photograph, never as a
claim about a real LabourMarket.ai user, and never on a production surface.
