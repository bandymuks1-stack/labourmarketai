## Priority classes

| Class | Meaning |
|---|---|
| P0 | Critical security, data integrity, a core function that does not work |
| P1 | Required for reliable commercial use |
| P2 | Highest-value functionality and UX improvements |
| P3 | Growth, automation, new markets |
