# Diagramų šaltiniai (Mermaid) — indeksas

Šie failai yra **redaguojami diagramų šaltiniai**, kuriuos dizaineris ar
programuotojas gali atkurti. Nugludinti SVG (`docs/presentation/svg/*.svg`)
kuriami atskirai; šie Mermaid šaltiniai atspindi tuos pačius kanoninius grafikus.

Visi diagramų šaltiniai:

- sektoriams neutralūs (branduolys nepriklauso nuo vienos profesijos);
- naudoja lietuviškas etiketes;
- Mermaid blokai apgaubti ```mermaid tvora ir sintaksiškai teisingi;
- faktai tik iš `../_FACTBASE.md`.

## Pastaba dėl pozicionavimo

Diagramose statyba ir Lietuva rodomos tik kaip pirmasis pilotinis vertikalas /
rinka, jei iš viso minimos. Branduolio srautai lieka sektoriams neutralūs.
Plėtros diagrama aiškiai pažymėta kaip **strateginė kryptis, ne prognozė.**
