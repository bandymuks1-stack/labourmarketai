# Complaint & Mediation — Future Scope

> **Future scope, not an active claim.** Nothing in this document describes a
> feature that works today. Do not state these as live capabilities in any public
> copy. Grounded in [`responsibility-matrix.md`](./responsibility-matrix.md).

## 1. Intent (future)

A future mediation and complaint path that could help market participants resolve
issues fairly and reduce risk:

- a **mediation centre** for disputes between parties;
- a **complaint / incident register**;
- **risk-history signals** for customers, partners and workers built from real,
  evidenced events;
- handling that stays fair and non-defamatory.

## 2. Hard rules

- These are **future** — never advertise them as already working.
- Any future implementation is owner-gated and, if it touches the database, ships
  as an additive, reversible, human-gated migration (no migration in this scope).
- The platform is not, by default, an arbiter; mediation would be an explicit,
  separately-contracted service (likely via the operating company).
- No fake cases, no fabricated risk history, no defamation.
