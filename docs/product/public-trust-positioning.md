# Public Trust Positioning

> The approved public message and the trust language for Labourmarket.ai. The
> hero, the main value blocks, and general product communication use this
> direction and **do not distort it**. Grounded in
> [`general-labour-market-platform-principle.md`](./general-labour-market-platform-principle.md).

## 1. The approved public message (do not distort)

**Primary:** *Labourmarket.ai — a general labour-market platform that helps
workers, employers, agencies and partners work more clearly, more transparently
and more reliably.*

**Secondary:** *Accurate profiles, clear needs, document-readiness signals, fair
agreements and reputation help reduce risk for every market participant.*

(LT primary: *„Labourmarket.ai — bendra darbo rinkos platforma, kuri padeda
darbuotojams, darbdaviams, agentūroms ir partneriams dirbti aiškiau, skaidriau ir
patikimiau.“* LT secondary: *„Tikslūs profiliai, aiškūs poreikiai, dokumentų
pasirengimo signalai, sąžiningi susitarimai ir reputacija padeda mažinti rizikas
visiems rinkos dalyviams.“*)

## 2. CTAs (real, neutral)

Use: "Sign in" / "Prisijungti" · "Create profile" / "Kurti profilį" · "Post a
need" / "Pateikti poreikį" · "Join the platform" / "Prisijungti prie platformos".

**Avoid:** "See the demo", "Demo preview", "Test demo", "Fake preview", "Instant
hire", "Verified workers", "Guaranteed match".

## 3. Value blocks

**Workers** — a more reliable CV / work profile; clearer described experience;
document-readiness signals; better visibility; building reputation; a higher
chance of more suitable offers. *Do not* use a strong "skill verification" claim;
prefer "reliable CV", "clearer profiles", "work experience and readiness signals",
"reputation history", "document-readiness signals".

**Employers** — clearer described needs; less ambiguity; better candidate /
partner comparison; document and readiness signals; fairer agreements; risk
reduction.

**Agencies & partners** — a place in a shared labour-market platform; better
visibility for fairly-operating partners; clearer needs; better management of
profiles / candidates / orders; reputation and history; trust-building, not closed
control.

## 4. Trust language — allowed vs forbidden

| Allowed | Forbidden in public copy |
|---|---|
| general labour-market platform | construction-only framing |
| reliable CV · clearer profiles | "we are the intermediary in construction" |
| document-readiness signals | "all construction clients must go through us" |
| reputation · fair agreements | "only through our company" |
| responsible recommendations | "demo preview" as landing character |
| risk reduction · trusted cooperation | "fake" / "mock" / "sample worker" in public UI |
|  | "verified skills" as a strong unbacked claim |
|  | "legally verified" · "licensed employment agency" (unconfirmed) |
|  | "guaranteed worker" · "guaranteed match" · "instant hire" |

## 5. Honest "being built" framing (when needed)

Where a feature is genuinely still being expanded, use a calm, honest phrase
("Some features are still being expanded in stages.") — never "demo", never "fake",
never "not real". The landing must read as an **early but real platform**, not a
mock demonstration. See [`general-labour-market-platform-principle.md`](./general-labour-market-platform-principle.md) §4.
