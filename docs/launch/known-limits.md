# Known limits (before launch)

Honest list of what is manual, not automated, or not yet built. Share-ready.

## Manual / owner-review (no automation yet)
- First-user approval and onboarding of early people/companies.
- Document verification and any "verified" status.
- Marketplace moderation (offer object + queue arrive in later PRs).
- Payments — none; first users onboarded manually.

## Signal, not guarantee
- Skill recognition from text → a **signal/suggestion**, confirmed by the user;
  never an external verification.
- Readiness / eligibility → honest status + legal routes; **no legal guarantee**.
- Map location → **signal-only**; a marker appears only with verified coordinates.

## Not built yet (planned, post-this-PR)
- Marketplace offer object + creation/publish + moderation queue.
- Brigade availability calendar (capacity on the map).
- Accommodation / tools / local-services persisted layers.
- Trust badges + verified company/location persistence.
- Action radar + opportunity gaps from live counts.
- Rate/price map from real data ("not enough data yet" until then).
- One persistent project-bound chat thread (additive migration, owner-gated).

## Payments (whole area inert)
- No checkout, no live billing, no paid unlocks, no invoices.
- Paid tiers are described only; widening is never enforced (no fake unlock).
- See [stripe-next-sprint-handoff.md](./stripe-next-sprint-handoff.md).

## Localization
- Active locales: LT / EN / RU. Other locale files exist but are not active.
