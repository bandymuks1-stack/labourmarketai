# Communication guide

## Inbox
- `/{locale}/dashboard/communication` is the real conversation inbox (participant-
  scoped). Conversations are 1:1 / subject-named threads.

## Project chat
- Each project shows a **"Pokalbis dėl projekto"** CTA and a Communication block.
- The CTA opens the **real inbox** with the project context shown — it is not a
  fake chat. A dedicated project-bound thread (one persistent thread tied to the
  project) is an additive migration in a later, owner-gated step.

## What a conversation can be about
- A company can start communication about: a project, a team/brigade, a worker, a
  need, or confirmations.
- A worker should understand whether a conversation is about a job offer, a
  project, documents, or skill confirmation (shown in context).

## Honesty
- No fake messages, no fabricated counterparts. If persistence for a flow is not
  wired, the UI states the honest next step instead of inventing a thread.

## Not active yet
- A single persistent project-bound thread (migration, later).
- Any paid messaging tier (payments are being prepared).
