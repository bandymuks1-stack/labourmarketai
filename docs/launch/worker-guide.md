# Worker guide (a person)

You are a **person** (Asmuo). You can look for work, do work, offer a small
service, buy a service, and ask for local help. You are never locked into one role.

## 1. Profile = your professional passport
- `/{locale}/dashboard/profile` holds your CV text, skills and work journal in one place.
- Skills you add are **self-declared** until backed by work entries or a manager —
  the UI always says honestly what is verified and what is not.

## 2. Work journal → skills
- Write what you did in plain language (LT works with or without diacritics).
- **Pressing Save runs skill recognition** and links the skills you already declared
  to that entry. This is *evidence support*, not external verification.
- Evidence status is one honest line: none / some / all of your skills have work backing.

## 3. Documents & readiness
- "Ready locally" vs "needs documents" is shown honestly.
- For another country **without the required documents**, you are *not* shown as
  "ready to work abroad". Instead you see legal-route options (company handles
  paperwork, document support, etc.). The system never promises legal eligibility.

## 4. Find work
- `/{locale}/dashboard/opportunities` shows matching work. Map signals are
  signal-only (no exact pin unless coordinates are verified).

## What is not active yet
- Paid features (none — payments are being prepared).
- Automatic verification of skills/documents (a human reviews first).
