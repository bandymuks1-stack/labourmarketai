### €1 smoke-test design — NOT EXECUTED (owner decision)

Goal: exercise (1)–(3) once with real money **without touching the €99 price real customers see** and without leaving a second sellable plan behind.

1. **Stripe Dashboard (LIVE):** create a *separate* product "LabourMarket.ai — smoke test (internal)" with one recurring price **€1.00/month**, tax behaviour exclusive. Copy its `price_…` id. Do **not** add it to the Organization product.
2. **Vercel (Preview scope only, never Production):** on a preview deployment of this branch set `STRIPE_PRICE_COMPANY_PILOT=<the €1 price id>` together with the live keys + `STRIPE_LIVE_ACTIVATION`. Production keeps `price_1UCKgg637uptAg5zD8dMA6kU`. The code has ONE price slot per plan, so the €1 id can never be selected by a production request.
3. **Webhook:** add the preview URL as a second LIVE endpoint with the same 10 events (+ `checkout.session.expired`); its own signing secret goes only to the preview env.
4. **Run:** owner signs in on the preview as an organization owner → Order → pay €1 → verify `billing_checkout_operations.completed`, `billing_subscriptions.active` with `provider_price_id = <€1 id>`, `unit_amount_cents = 100`, `GET /api/billing/reconcile` → expect exactly one anomaly `unexpected_price` (the preview's plans table still says €99) — which is itself the proof that amount reconciliation works. Click Order again → `409 subscription_exists`.
5. **Cancel in Stripe** (Customer Portal or dashboard) → `customer.subscription.deleted` → row `cancelled`; then **refund** the €1 → `charge.refunded` recorded record-only. Delete the preview webhook endpoint and archive the €1 price.
6. **Residue:** one archived €1 price on the LIVE account, one cancelled €1 subscription in Stripe history, preview-DB rows only if the preview pointed at a preview database — **the preview must not use the production Supabase project**, or the rows land in prod and must be cleaned via the paired rollback discipline (never a silent delete).

The alternative the owner already scheduled (G-8 step 7: pay the real €99 with the owner's own organization and refund) proves the same three things against the real price at the cost of a €99 charge + refund; it needs no preview environment. Either path is an owner decision; neither has been executed by this branch.
