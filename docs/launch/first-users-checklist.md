# First users — owner checklist

Open and check these yourself before inviting the first people and companies.
Production: https://labourmarket.ai

## Public + SEO
- [ ] `/lt`, `/en`, `/ru` load (200) and read correctly per language.
- [ ] `/robots.txt` and `/sitemap.xml` return 200.
- [ ] No demo/mock/fake/pilot wording in public copy; no old/external project names.

## Identity + onboarding
- [ ] Sign up as a **person**; onboarding presents the person identity first.
- [ ] Role switcher shows **Asmens erdvė / Įmonės erdvė** only (no Agentūra / Pirkėjas).
- [ ] Create a **company**; confirm hire/buy/sell/need/projects are actions, not identities.

## Worker path
- [ ] Fill profile; skills show honest "self-declared / not verified".
- [ ] Write a journal entry → **Save** → skills get recognised/linked; evidence status
      reads as one consistent line (none/some/all), no contradiction.

## Company path
- [ ] Raise a need (describe → criteria → review → submit) — saved as a real request.
- [ ] Open a project → see a **location signal** (no fake marker) + **"Pokalbis dėl
      projekto"** CTA into the real inbox.

## Map + marketplace
- [ ] `/lt/dashboard/market-map` is signal-only; no exact markers without verified coords.
- [ ] No live marketplace offers are publishable yet (expected — later PRs).

## Admin + safety
- [ ] `/lt/dashboard/admin` as a non-admin redirects to login (no 500, not visible).
- [ ] Payments: confirm copy says payments are being prepared; no `pay now`, no
      `subscription active`, no paid unlock.

## Mobile
- [ ] On a phone (360–430px): no clipped CTAs, action rows stack, pickers are dark.

## Before inviting
- [ ] Decide how you approve first users (owner-review) and verify documents manually.
- [ ] Read [known-limits.md](./known-limits.md) so you can answer "what's not automated yet".
- [ ] Confirm live billing is OFF (it is, by default and by guard).
